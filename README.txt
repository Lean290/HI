Publish with GitHub Pages
1. Open your GitHub repository.
2. Upload these files directly to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Your site should be available at https://lean290.github.io/MyPortfolio/

Before publishing
- Confirm that your contact details are correct.
- Add real project names, screenshots, and descriptions when you are ready.
- Do not add private information that you do not want publicly visible.
